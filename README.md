# CPSC362-unchud-app
## What does this app do?
This app will allow users to track what assignments they must do via manual input, and later Canvas integration. With every assignment marked as complete the user will earn some form of currency to purchase an accessory to customize their avatar. If an assignment is marked by its deadline, a random accessory from the user's inventory will be repossessed.
## What is the purpose of this app?
The purpose of this app is to aid students dealing with procrastination and make completing assignments more fun.
